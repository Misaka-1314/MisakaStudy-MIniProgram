# 自建小程序教程

:::warning
非开源版小程序，原则上仅用于自己和同学朋友使用。  
明确禁止用于除微信官方广告以外的牟利（包括但不限于倒卖、引流其他产品等），除非分我。
:::

:::tip
开发者依靠激励广告获得收益，这是我们更新的动力！  
不支持去除广告、公众号卡片，正式版仅允许更换轮播图（需要图床链接）。
:::

## 一、前置步骤

1. 注册小程序 [微信公众平台](https://mp.weixin.qq.com)
2. 设置小程序名称、简称、简介、图标（随便填写）
3. 设置小程序类目、主营类目 (推荐类目写在下面)

::: details 如果需要发布线上版本
1. 注册小程序 [微信公众平台](https://mp.weixin.qq.com)
2. 设置小程序名称、简称、简介、图标（随便填写）
3. 设置小程序类目、主营类目 (推荐类目写在下面)
4. 小程序备案 (免费，必须) + 小程序微信认证 (非企业30元/年，可选)
5. 申请小程序开发接口 (至少需要 `wx.chooseLocation`，可选 `wx.getLocation`)
:::

推荐的小程序类目（没特殊需要就照着选）
> 教育服务 > 在线教育  
> 工具 > 办公  
> 工具 > 计算器  
> 体育 > 在线健身  
> 工具 > 信息查询

## 附：常见问题

#### 1. 为什么要自建小程序？

2024年4月，某人才举报了大量相关小程序，建议自建小程序备用！

#### 2. 如何修改签到 IP？

如果您是自建小程序用户，并无偿对公众提供稳定服务，我们支持使用自建的服务器进行签到。  
您可以参考 [反代服务器搭建教程](../open/server.md) 搭建自己的服务器，即可使用服务器 IP 进行签到。
如有使用校内 IP 签到的需求，可以采用 FRP 之类的工具内网穿透（但需保证服务可靠性）。
